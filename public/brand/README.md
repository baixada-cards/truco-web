# Product material assets

`rich-walnut.webp` is the production Baixada table surface. It was created
specifically for this project during the July 2026 art-direction work and is
not a third-party stock photograph.

Keep product-specific photographic material here. Shared color, typography,
paper, spacing, and focus contracts belong in
`@baixada-cards/design-system`; consumer bindings live in
`src/baixada-product.css`.
